# 실습 환경과 검증 범위

## 실습 모드

| 모드 | 필요한 환경 | 확인할 수 있는 것 | 확인하지 않는 것 |
|---|---|---|---|
| 규칙·mock | Python 가상환경, 예제 의존성 | 데이터 흐름·가드·시뮬레이션 | 실제 모델 성능·네트워크 공격 성공 |
| 로컬 모델 | Ollama, 명시된 모델, 다운로드 공간 | 해당 모델의 응답 | 클라우드 API 동작 |
| API | 공급자 계정·키·통신 허용·예산 | 해당 시점 모델의 응답 | 동일 응답의 재현 보장 |
| 실제 표적 확장 | 격리 Linux VM, Docker, 센서·로그 연결 | 구성한 환경의 동작 | 운영망 안전성·실전 성능 일반화 |

`labs/run_lab.py`는 합성 서비스 시뮬레이션이며 `--live` 옵션이 없다.
Docker 표적을 띄우는 것만으로 attacker·defender·Zeek가 통합되지는 않는다.
Colab 노트북과 로컬 Docker 실습은 별개다. 합성 데이터에 다운로드가 필요하지 않더라도
임베딩 모델·Ollama 모델·컨테이너 이미지는 첫 실행 전에 받아야 한다.

## 전체 실행 기록 (2026-10-06)

`requirements.txt` 기준으로 확정한 잠금 파일을 **시스템 패키지가 없는 새 가상환경에 설치**하고,
그 Python의 절대 경로를 커널로 지정해 v4 강사용 노트북 18개를 전량 실행했다. 결과는 **18 OK · 0 FAIL · 0 SKIP**이며 `solutions/`의 완성본은
이 실행의 출력이다.

| 구성 요소 | 검증 버전 |
|---|---|
| OS / Python | Linux 6.8 / 3.10.12 |
| anthropic | 1.11.0 |
| mcp | 1.30.0 |
| chromadb | 1.5.9 |
| sentence-transformers | 6.1.0 |
| scikit-learn | 1.7.2 |
| numpy / pandas | 2.2.6 / 2.3.3 |
| 로컬 모델 | ollama llama3.2:3b · 임베딩 all-MiniLM-L6-v2 |

전체 `pip freeze` 결과는 공개 배포본 루트의 `requirements-lock.txt`에
있다. `requirements.txt`는 최소 버전 조건이므로, 그대로 설치하면 더 새 버전이 깔릴 수 있다.
재현이 필요하면 잠금 파일의 버전을 그대로 쓴다.

검증하지 않은 범위는 다음과 같다. 유료 API 응답의 재현성, Docker 표적을 띄우는 통합 실습,
Colab 런타임, 다른 OS·Python 버전이다. 실행하지 않은 환경을 검증된 잠금 파일로 배포하지 않는다.

## 실행 전 확인

- Docker·Ollama·ChromaDB를 함께 사용하는 구성은 16GB RAM을 출발점으로 삼되,
  모델 크기·양자화·동시 프로세스에 따라 필요량을 측정한다.
- API 비용은 호출 수 × 입력·출력 토큰 × 실행 당일 단가로 산정한다. 키가 설정된 노트북은
  유료 호출을 할 수 있으므로 실행 전에 모드를 확인한다.
- 과거 보고서의 실행 시간은 당시 환경의 관찰값이며 다운로드 시간이나 다른 하드웨어의 시간을 보장하지 않는다.
- 모델 다운로드 오류는 네트워크·캐시·디스크 공간을, import 오류는 커널의 Python과 설치 환경을 확인한다.
- 수정 노트북의 출력과 실행 상태는 `solutions/_validation_report.md`를 확인한다.

## v5 배포 안내

v5는 본문·점수 정의·예제 안내를 교정한 판본입니다. 노트북 코드와 저장된 출력은
v4에서 전체 실행한 것과 동일하며, 위 실행 기록을 그대로 적용합니다.
본문의 표적 단위 점수 계산은 배포된 `labs/defender/score.py`와 같은 코드입니다.
정정 이력과 제보 방법은 배포 루트의 `ERRATA.md`를 참고하세요.

## v6 배포 안내

v6는 ch24 본문 예제와 배포 코드의 차이 및 ch27 확장 구성 설명을 교정했습니다.
노트북 코드·저장 출력과 labs 실행 소스는 v5와 같으며, 기존 전체 실행 기록을 승계합니다.
빠른 시작에서는 위 검증 환경과 잠금 파일을 우선 안내합니다. 전체 API 실습의 새 실행 기록은 아닙니다.
