# 실습 환경과 검증 범위

## 실습 모드

| 모드 | 필요한 환경 | 확인할 수 있는 것 | 확인하지 않는 것 |
|---|---|---|---|
| 규칙·mock | Python 가상환경, 예제 의존성 | 데이터 흐름·가드·시뮬레이션 | 실제 모델 성능·네트워크 공격 성공 |
| 로컬 모델 | Ollama, 명시된 모델, 다운로드 공간 | 해당 모델의 응답 | 클라우드 API 동작 |
| API | 공급자 계정·키·통신 허용·예산 | 해당 시점 모델의 응답 | 동일 응답의 재현 보장 |
| 실제 표적 확장 | 격리 Linux VM, Docker, 센서·로그 연결 | 구성한 환경의 동작 | 운영망 안전성·실전 성능 일반화 |

`labs/run_lab.py`는 합성 서비스 시뮬레이션이며 `--live` 옵션이 없다.
Docker 표적을 띄우는 것만으로 attacker·defender·Zeek가 통합되지는 않는다.
Colab 노트북과 로컬 Docker 실습은 별개다. 합성 데이터에 다운로드가 필요하지 않더라도
임베딩 모델·Ollama 모델·컨테이너 이미지는 첫 실행 전에 받아야 한다.

## 기존 전체 실행 기록

2026-09-16 보고서의 환경이다. 현재 수정본의 전체 재실행을 의미하지 않는다.

| 구성 요소 | 당시 기록 |
|---|---|
| Python | 3.12.5 |
| anthropic | 1.5.0 |
| mcp | 1.30.0 |
| chromadb | 1.5.9 |
| sentence-transformers | 6.0.1 |
| scikit-learn | 1.9.1 |

`requirements.txt`는 최소 버전 조건이며 최신 버전의 호환성을 보장하지 않는다.
위 표는 전체 잠금 파일도 아니다. 출간용 전체 실행은 새 가상환경에서 수행하고, 그 환경의
`python -m pip freeze` 결과와 Python·OS·모델 식별자를 함께 보관한다.
실행하지 않은 환경을 검증된 잠금 파일로 배포하지 않는다.

## 실행 전 확인

- Docker·Ollama·ChromaDB를 함께 사용하는 구성은 16GB RAM을 출발점으로 삼되,
  모델 크기·양자화·동시 프로세스에 따라 필요량을 측정한다.
- API 비용은 호출 수 × 입력·출력 토큰 × 실행 당일 단가로 산정한다. 키가 설정된 노트북은
  유료 호출을 할 수 있으므로 실행 전에 모드를 확인한다.
- 과거 보고서의 실행 시간은 당시 환경의 관찰값이며 다운로드 시간이나 다른 하드웨어의 시간을 보장하지 않는다.
- 모델 다운로드 오류는 네트워크·캐시·디스크 공간을, import 오류는 커널의 Python과 설치 환경을 확인한다.
- 수정 노트북의 출력과 실행 상태는 `solutions/_validation_report.md`를 확인한다.
